# Zahra Bahrami — Psychotherapy website

Static website for GitHub Pages, with 4 main navigation pages plus a homepage.

## How to publish
1. Extract this ZIP.
2. In your existing GitHub repository `zahrabahrami.com`, choose **Add file → Upload files**.
3. Upload **all contents** of the extracted folder (including the `assets` folder), not the ZIP itself.
4. Commit changes. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
5. To connect Cloudflare, set the GitHub Pages custom domain to `zahrabahrami.com` and configure DNS as GitHub documents. Do not guess IP addresses.
6. Enable **Enforce HTTPS** when available.
